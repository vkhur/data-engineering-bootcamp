# Project 1: Supply Chain Data Engineering Platform

## Business Problem

A global supply chain organization needs a data platform to analyze:
- Customer orders
- Product performance
- Inventory levels
- Supplier performance
- Shipment delays

The goal is to build an end-to-end data engineering pipeline that transforms raw operational data into business insights.

---

## Objectives

1. Extract data from raw files
2. Clean and transform data using Python
3. Store data in PostgreSQL
4. Design analytical data models
5. Create dashboards for decision-making
6. Deploy components on AWS
